# Архитектура scisdvig

Статус: проектирование.
Наличие компонента в схеме не означает его реализации.

## Границы компонентов

| Компонент | Ответственность |
| :--- | :--- |
| Web UI | Загрузка, прогресс, решения пользователя, экспорт |
| Прикладной слой | Команды заданию, допустимые переходы, отмена, сроки |
| LangGraph workflow | Порядок этапов и маршрутизация |
| Обработка документов | Извлечение, структура, ресурсы, очистка |
| Перевод | Фрагменты, терминология, постобработка, проверка |
| Адаптер модели | Вызов runtime, результат, ошибки, usage |
| Хранение | Артефакты, версии глоссария, сведения запуска |
| Экспорт | Сборка и выдача результата |

## Предлагаемый поток

Загрузка и сохранение оригинала
→ извлечение содержимого и доступной структуры без очистки
→ сохранение извлечённого представления
→ проверка инъекций
→ при необходимости решение пользователя
→ уточнение типов блоков и связей
→ формирование представления для перевода:
    сохранить содержательные блоки,
    исключить подтверждённые служебные элементы,
    зафиксировать решения
→ контроль полноты подготовки
→ глоссарий → принятие/редактирование
→ перевод → постобработка
→ сборка текста, примечаний и ссылок
→ проверка полноты и связности
→ результат → экспорт

Отмена и ошибки описываются в таблице переходов.
Положение OCR/layout-операций уточняется отдельно.
