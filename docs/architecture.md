# Архитектура scisdvig

Статус: проектирование.
Наличие компонента в схеме не означает его реализации.

## Границы компонентов

| Компонент | Ответственность |
| :--- | :--- |
| Web UI | Загрузка, прогресс, решения пользователя, экспорт |
| Прикладной слой | Команды заданию, допустимые переходы, отмена, сроки |
| LangGraph workflow | Порядок этапов и маршрутизация |
| Обработка документов | Извлечение, структура, ресурсы, очистка |
| Перевод | Фрагменты, терминология, постобработка, проверка |
| Адаптер модели | Вызов runtime, результат, ошибки, usage |
| Хранение | Артефакты, версии глоссария, сведения запуска |
| Экспорт | Сборка и выдача результата |

## Предлагаемый поток

Загрузка и сохранение оригинала
→ извлечение содержимого и доступной структуры без очистки
→ сохранение извлечённого представления
→ проверка инъекций
→ при необходимости решение пользователя
→ уточнение типов блоков и связей
→ формирование представления для перевода:
    сохранить содержательные блоки,
    исключить подтверждённые служебные элементы,
    зафиксировать решения
→ контроль полноты подготовки
→ глоссарий → принятие/редактирование
→ перевод → постобработка
→ сборка текста, примечаний и ссылок
→ проверка полноты и связности
→ результат → экспорт

Отмена и ошибки описываются в таблице переходов.
Положение OCR/layout-операций уточняется отдельно.

## Модели локального инференса (кандидаты)

Реестр ведётся здесь; выбор и замена фиксируются в `ADR-003`. Назначение по этапам — рабочая гипотеза, подлежит проверке замерами на целевой станции.

| Модель | Предполагаемое назначение | Примечание |
| :--- | :--- | :--- |
| translategemma-12b-it-8bit | основной технический перевод (регламенты, стандарты, 3GPP, RFC) | кандидат по умолчанию |
| translategemma-4b-it-4bit | предпросмотр страницы до обращения к тяжёлой модели | `TS-02`, `TS-03` |
| Index-Translate-2B / Index-Translate-9B | кандидаты на перевод | требуют локального замера |
| Hunyuan-MT-7B / Hunyuan-MT-Chimera-7B | кандидаты на перевод | требуют локального замера |
| MADLAD400-3B | кандидат на постобработку/предпросмотр | требует локального замера |
| OPUS-MT EN→RU, M2M100-418M | базовые линии сравнения | не генеративные инструктивные |
| translateGemma-27B-it | основной перевод, если позволит станция | проверка по `NF-REQ-04` |
| TowerInstruct-7B-v0.2 | кандидат на постобработку | требует локального замера |
| Qwen3-30B-A3B-Instruct-2507 | запасной вариант тяжёлой модели | проверка памяти по `NF-REQ-04` |
