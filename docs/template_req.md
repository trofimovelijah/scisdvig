## REQ-007. Учёт текстовых фрагментов

Статус: `draft`

Формулировка:
Каждый текстовый фрагмент, переданный на перевод, должен получить результат обработки: перевод либо явную ошибку.

Критерии приёмки:
- Каждый входной fragment_id присутствует в отчёте обработки.
- Для каждого fragment_id указан один итоговый статус.
- Ошибка отдельного фрагмента не скрывается под общим статусом успеха.

Проверка:
Интеграционный тест с адаптером-заглушкой, который возвращает успех для одного фрагмента и ошибку для другого.
