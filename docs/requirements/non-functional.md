# Ограничения и нефункциональные требования

НФТ-01. Допускается возможность запуска моделей либо локально, либо по API

НФТ-02. Для оркестрации процесса распознавания используется LangGraph

НФТ-03. Для работы приложения должны использоваться только библиотеки и пакеты с открытыми исходными текстами

НФТ-04. Запуск приложения должен осуществляться с одного ноутбука

НФТ-05. LLM, используемые локально, должны обладать подходящими лицензиями для работы без ограничений и с открытыми весами

НФТ-06. Допустимо ожидание при переключении модели (не миллисекунды, а секунды)
> с точки зрения пользователя функциональные кнопки не должны быть активными в момент переключения
> при простое более двух секунд должна появляться надпись "идёт переключение моделей"
> после надпись меняется на "модель готова" (см. ТИ-05)

НФТ-07. Каждый State в LangGraph должен использовать согласно PEP8 snake_case с упоминанием функционального назначения из требований
