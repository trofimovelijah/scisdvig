## NF-REQ-04. Запуск приложения должен осуществляться с одной рабочей станции

Статус: `draft`

Формулировка:
> Запуск приложения должен осуществляться с одной рабочей станции.
>
> В качестве рабочей станции для MVP используется MacBook M5 Pro (Silicon, 64 Gb RAM, 1Tb SSD)
>
> В качестве средств запуска приложения необходимо использовать инструменты контейнеризации (docker/docker-compose с учётом MacOS), способные оркестрировать в том числе LLM.
>
> Инструменты типа `k8s` использовать не требуется ввиду их повышенной сложности для подобного локального приложения.

## NF-REQ-06. Допустимо ожидание при переключении модели

Статус: `draft`

Формулировка:
> Допустимо ожидание при переключении модели: не миллисекунды, а секунды.
>
> С точки зрения пользователя функциональные кнопки не должны быть активными в момент переключения. При простое более двух секунд должна появляться надпись "_идёт переключение моделей_".
>
> После надпись меняется на "модель готова" (см. TS-05)

## NF-REQ-08. Переведённые документы хранятся локально на сервере запуска приложения

Статус: `draft`

Формулировка:
> Переведённые документы хранятся локально на сервере запуска приложения.
>
> Например, в директории `depositary` текущего репозитория.
>
> Документы должны храниться упорядоченно в директориях по выделенному признаку (например, каталог по датам)
