# Почему выбран существенный вариант
 
Карточка документа - конкретное изменение, ограничения и проверки. ADR-00N - наименование Карточки.

Статусы ADR: 
  - proposed, 
  - accepted, 
  - rejected, 
  - superseded. 

Итерация — отдельное поле, а не статус. 

Принятый ADR не означает, что решение уже реализовано.
