# ADR-003. Выбор моделей локального инференса

Статус: 'proposed'
Дата предложения: 2026-11-26
Итерация: I1 — первый сквозной локальный запуск
Основания: `F-REQ-04/09/12`, `NF-REQ-04/05`, `TS-01/02/03`
Заменяет: нет

## Контекст

Приложение использует несколько моделей по этапам: перевод, формирование глоссария, постобработка, предпросмотр.
Модель и runtime на момент карточки не выбраны и числятся нерешённым вопросом.
Реестр кандидатов ведётся в `docs/architecture.md`.

## Критерии выбора

Соответствие лицензии (`NF-REQ-05`), запуск на целевой станции (`NF-REQ-04`), поддержка EN→RU,
качество на локальном контрольном наборе, удобство замены через адаптер (`ADR-001`).

## Предлагаемое решение

- Модели назначаются поэтапно из реестра; использование модели вне реестра запрещено.
- По умолчанию: `translategemma-12b-it-8bit` — основной перевод, `translategemma-4b-it-4bit` — предпросмотр.
- Остальные кандидаты переводятся в выбранные только после локальных замеров памяти, скорости и качества;
  выводы о качестве по чужим бенчмаркам не делаются.
- Замена модели выполняется конфигурацией и адаптером.

## Последствия

Плюсы:
  - единая точка учёта моделей и лицензий,
  - замена без правок workflow.

Издержки: нужен локальный контрольный набор и фиксация методики замеров до перевода статуса в `accepted`.

## Проверка

- Каждая выбранная модель запущена локально на целевой станции; лицензия зафиксирована.
- Замеры памяти и скорости приложены к карточке.
- Замена модели на контрольном сценарии не трогает код вне адаптера.
