# Состояния
backlog → ready → in-progress → done

Дополнительно `blocked`, если работа действительно остановлена внешним условием.

Правила:

  - `ready` означает, что связанные требования приняты и работа ограничена понятным результатом,
  - одновременно у одного исполнителя — одна основная функция `in-progress`.
  - мелкие шаги находятся в чек-листе карточки функции, а не отдельными строками `backlog`.
  - дефект оформляется отдельной строкой, только если его не исправляют сразу в текущей работе.
  - историю изменения состояний хранит Git — отдельный журнал перемещений не нужен.
