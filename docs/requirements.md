# Требования MVP

## 1. Цель
Какие документы и для какой практической задачи переводим.

## 2. Границы MVP
### Входит
### Не входит

## 3. Условия использования
Среда выполнения, языковые пары, входные и выходные форматы.

## 4. Пользовательские сценарии
ПТ-01. Пользователь должен иметь возможность загружать документ через веб-интерфейс

ПТ-02. При невозможности загрузить документ пользователю должна возвращаться удобочитаемая информация о причине отсутствия возможности загрузки
```txt
К таковым относятся:
  - превышение размера документа
  - не поддерживаемый формат документа
```

ПТ-03. Допустимый размер загружаемого документа ограничен `200 Mb`.

ПТ-04. Пользователь должен видеть прогресс выполнения обработки документа

## 5. Функциональные требования

ФТ-01. Приложение должно распознавать текстовый документ для дальнейшего перевода

ФТ-02. Для распознавания доступен документ в форматах pdf

ФТ-03. Для распознавания доступен документ в текстовом формате
```txt
К текстовым форматам относятся txt, md, ascii
```

ФТ-04. Перевод осуществляется с помощью LLM

ФТ-05. Приложение ориентировано на перевод технической документации на русский язык
```txt
Предположительно в большинстве случаев язык оригинала документа -- английский.
```

ФТ-06. Изображения в переводимых документах должны извлекаться и вставляться в перевод без изменений

ФТ-07. Перед выполнением перевода должен формироваться глоссарий документа
```txt
Глоссарий содержит термины и определения непосредственно из переводимого документа, а также термины, которые могут встерчаться в документе, но иметь двузначный перевод.
```

ФТ-08. Перед переводом должна выполняться классификация тематики текста для выбора оптимальной модели или подхода

ФТ-09. Опционально возможна постобработка для вычитки и улучшения стиля лёгкой моделью

## 6. Ограничения и нефункциональные требования

НФТ-01. Допускается возможность запуска моделей либо локально, либо по API

НФТ-02. Для оркестрации процесса распознавания используется LangGraph

НФТ-03. Для работы приложения должны использоваться только библиотеки и пакеты с открытыми исходными текстами

НФТ-04. Запуск приложения должен осуществляться с одного ноутбука

НФТ-05. LLM, используемые локально, должны обладать подходящими лицензиями для работы без ограничений и с открытыми весами
